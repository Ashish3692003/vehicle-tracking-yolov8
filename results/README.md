# Results

This directory contains the output results generated by the vehicle detection and tracking pipeline.

## Output Format

When you run the detection pipeline on an input video, the following outputs are generated:

- **Processed Video** (`car-detection-processed.mp4`)
  - The original input video with bounding boxes, class labels, and tracking IDs overlaid on each frame.
  - Vehicles are color-coded by class (Car, Bus, Truck) for easy visual identification.

- **Detection Frame Samples** (optional)
  - Individual frames can be extracted showing detection quality and tracking consistency.

## Key Performance Metrics

| Metric | Value | Description |
|--------|-------|-------------|
| **Model** | YOLOv8n | Lightweight version for real-time inference |
| **Tracker** | ByteTrack | Robust multi-object tracking with occlusion handling |
| **Classes Detected** | 3 | Car (ID: 2), Bus (ID: 5), Truck (ID: 7) |
| **Counting Method** | Spatial Line-Based | Vehicles counted when centroid crosses a horizontal line |
| **Inference Speed** | ~30 FPS (varies by hardware) | Real-time capable |

## How to View Results

### Option 1: Run the Pipeline Yourself

```bash
python src/detect_vehicles.py \
  --input data/car-detection.mp4 \
  --output results/car-detection-processed.mp4
```

The processed video with bounding boxes and tracking IDs will be saved in the `results/` directory.

### Option 2: Run via Google Colab

Use the [Google Colab Notebook](https://colab.research.google.com/github/Ashish3692003/vehicle-tracking-yolov8/blob/main/notebooks/Vehicle_Detection.ipynb) for a cloud-based execution with visual outputs.

## Result Visualization

### Detection Output Structure

```
results/
├── README.md                         # This file
├── car-detection-processed.mp4       # Processed video with bounding boxes
└── vehicle_count_log.txt             # (Optional) Per-frame vehicle count log
```

### What You Will See in the Output Video

1. **Bounding Boxes** — Colored rectangles around each detected vehicle.
2. **Class Labels** — Text labels showing vehicle type (Car/Bus/Truck).
3. **Tracking IDs** — Unique numeric IDs assigned to each tracked vehicle.
4. **Vehicle Counters** — Real-time count of total vehicles detected per class.

## Expected Results from MLSAVA Study

Based on the MLSAVA case study (Intel IoV dataset), the pipeline achieves:

- **High detection accuracy** for Cars, Buses, and Trucks in urban traffic scenarios.
- **Reliable tracking** across frames even during partial occlusion.
- **Accurate vehicle counting** using a horizontal counting line approach.

> **Note:** The actual output files (processed video, count logs) are generated at runtime and are not stored in the Git repository to keep the repo lightweight. See `.gitignore` for excluded file patterns.
